# pi-seedgrow

<p align="center"><img src="preview.svg" width="640" alt="the 10 growth frames" /></p>

A seed that grows into a sprout 🌱 for your [Pi](https://github.com/badlogic/pi-mono) loading bar.

While the agent works, the indicator cycles through 10 hand-built animation frames:
the seed is buried, peeks out, cracks, sprouts, grows leaves — then sways in the
wind until the turn finishes.

Frames: `U+E900–U+E909` (Unicode Private Use Area) from `seedgrow.ttf`,
a 3.4 KB TrueType icon font built **from raw bytes in pure Python** — no font editor.

| frame | stage |
|---|---|
| U+E900 | buried seed |
| U+E901 | peeking |
| U+E902 | cracked |
| U+E903 | tip out |
| U+E904 | bare shoot |
| U+E905 | leaf buds |
| U+E906 | leaves opening |
| U+E907 | full sprout |
| U+E908 | sway left |
| U+E909 | sway right |

Inspired by [pi-runcat](https://github.com/FredySandoval/pi-runcat) 🐱

## Install

### 1. Install the font

macOS:

```bash
curl -L -o ~/Library/Fonts/seedgrow.ttf "https://github.com/leovoon/pi-seedgrow/raw/main/seedgrow.ttf"
# restart the terminal app; if the font still doesn't appear:
atsutil databases -removeUser
```

Linux:

```bash
wget -P ~/.local/share/fonts "https://github.com/leovoon/pi-seedgrow/raw/main/seedgrow.ttf"
fc-cache -f
```

### 2. Ghostty users

Point the Private Use Area codepoints at the font family ("SeedGrow") in
`~/.config/ghostty/config`:

```
font-codepoint-map = U+E900-U+E909=SeedGrow
```

(If you use pi-runcat alongside, note both fonts claim U+E900–E904 — give
SeedGrow the range and disable one of the two extensions.)

### 3. Install the extension

```bash
pi install npm:pi-seedgrow
```

or install straight from this repo:

```bash
pi install git:github.com/leovoon/pi-seedgrow
```

## Uninstall

```bash
pi remove npm:pi-seedgrow
rm ~/Library/Fonts/seedgrow.ttf   # macOS
```
